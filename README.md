# 原神赌场：德州扑克

原神千星奇域 7.2 的中文德州扑克项目，使用超限模式，目标为最多八席的固定盲注 Casual。正式规则见 [DesignPlan.md](DesignPlan.md)。

## 当前进度

已确认开发关卡的人数设置为 1～8 人、所有人、必要分组。允许单人进入是为了调试界面；真正发牌仍要求至少两名有效玩家。

当前提供第一份客户端通信测试脚本，尚不是可直接导入的完整德州关卡。UI 控件、脚本映射和服务器节点需要在千星编辑器中配置；仓库暂不含已经试玩通过的 `.gil` / `.gia` 导出文件。

## 从这里开始

1. 按 [界面测试操作说明](docs/01-ui-probe.md) 创建一个客户端控件容器、状态文本和按钮。
2. 将 [ConnectionProbe.lua](client/dev/ConnectionProbe.lua) 映射并挂载到指定客户端容器节点。
3. 按 [信号约定](docs/02-signal-contract.md) 核对服务器回包节点；未接服务器时显示超时是预期状态。
4. 在游戏内完成单人及双人验证，再继续座位、买入、发牌和下注。

脚本只做通信测试，不发放丘丘币、不下注、不决定输赢。正式牌局和资产由服务器节点图管理。

## 文件与编辑器的关系

| 内容 | 存放位置 |
| --- | --- |
| 规则与开发状态 | `DesignPlan.md` |
| 客户端 Lua | `client/` |
| 操作说明和信号定义 | `docs/` |
| 场景、控件布局、服务器节点图 | 千星编辑器内；后续导出关卡再加入版本管理 |

把 Lua 文件放进 Git 不会自动让游戏使用它：必须建立脚本映射、挂载脚本并保存关卡。每次修改脚本后重新保存并试玩验证。

## 当前验证范围

代码按官方客户端 Lua API 编写。本地模拟用于检查请求、回包和超时分支，不能替代千星 Lua 5.3 宿主中的实测。游戏内的输入、激活状态、信号来源及双人定向发送仍需按操作说明验收。
